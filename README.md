# Symulacja Numeryczna Wahadła Fizycznego z Zespołem Sprężystym (RK4)

Projekt realizowany w ramach laboratoriów na Wydziale Mechanicznym Energetyki i Lotnictwa (MEiL). Podstawa projektu jest zagadnienie domowe, zad.7 (https://ccfd.github.io/courses/info2_projekty.html) zmodyfikowane w celu uniknięcia rozwiązania tych samych zadań przez kilku członków grupy laboratoryjnej, wprowadzone zmiany do zagadnienia poczatkowego w * [zadanie 7 modyfikacja](img/zad7(mod.).png)  Celem projektu było zbadanie nieliniowego równania ruchu wahadła fizycznego współpracującego ze sprężynami o charakterystyce liniowej, albo nieliniowej, przy użyciu algorytmu **Rungego-Kutty IV rzędu (RK4)**.
